# Kintsugi ledger: LibreGEO-Claude-Code

Kintsugi mends broken pottery with gold, so the repair becomes the part you look at. Here every crack this pack has had gets a row: what was wrong, the evidence, and the seal, left in plain sight instead of patched over.

Rows marked `hallmarked` were sealed in the 1.0.0 release ([#2](https://github.com/HermeticOrmus/LibreGEO-Claude-Code/pull/2)), which was verified by installing the plugin from GitHub into a clean Claude Code config. Open rows are cracks we know about and have not sealed yet; anyone can pick one up.

Grades: **hairline** is copy or cosmetic, **fracture** is wrong behavior with a workaround, **break** means it does not work, loses data, or breaks a safety or privacy promise.
