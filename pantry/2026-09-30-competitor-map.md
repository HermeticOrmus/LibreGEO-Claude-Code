## Product

- Name: LibreGEO-Claude-Code, v1.0.0 (read from `main` at `79e6aaa` on 2026-09-30)
- Flagship: `/geo-audit`, a full-site GEO and SEO audit that fans out to five subagents and returns a composite GEO Score (0-100)
- Our surfaces: one root plugin `libre-geo` in the marketplace `libre-geo` (`.claude-plugin/marketplace.json`, `"source": "./"`), holding 12 skills (`skills/*/SKILL.md`) and 5 agents (`agents/*.md`); bundled Python scripts in `skills/geo/scripts/`; JSON-LD templates in `skills/geo/schema/` and `templates/`; `setup.sh` installs through the Claude Code CLI. Install: `/plugin marketplace add HermeticOrmus/LibreGEO-Claude-Code`, then `/plugin install libre-geo@libre-geo`.
- Upstream: six skills (`geo-content`, `geo-platform-optimizer`, `geo-report`, `geo-report-pdf`, `geo-schema`, `geo-technical`) and all five agents come from zubair-trabzada/geo-seo-claude (MIT), per `NOTICE.md`. That repo is listed below as a competitor because people install it directly.

Star counts are from the GitHub API (`gh api repos/<owner>/<repo>`) on 2026-09-30.
